# CommunityResourcePocketRef
## Mission:
The pocket reference we are building is a small book listing local resources for survival. Resources are ordered loosely by Maslow's Hierarchy of Needs.
## Contribution:
This Project is a template for the creation of these references. PLEASE DO NOT INCLUDE REFERENCES TO LOCAL SERVICES.
This Project is written in LaTeX and follows a basic hierarchy:
1. Food
  - All Food Resources
    - Food Resources For Emergency Use
    - Food Resources For Stabilizing Food Supply 
2. Water
  - Water Resources
    - Water Resources For Emergency Use
    - Water Resources For Stabilizing Water Supply 
3. Shelter
  - Shelter Resources
    - Shelter Resources For Emergency Use
    - Seeking Longer Term Shelter
4. Security
  - Security Of Property Resources
    - Things like overnight lockers and securing items for short spans of time
    - Long Term Storage
5. Travel
  - Things like Public Transit options
    - Commuting to Work
    - Long Distance Travel
    - One Way Travel
## Hierarchy of Needs
This reference needs to be readable to people in a panic. This reference seeks to help an individual navigate getting their most basic needs met so they can rebuild their life on their terms. This idea is based on Maslow's Hierarchy of Needs which while a far from perfect model for psychology is a starting point for our purposes. We welcome any input on changing this strategy.
